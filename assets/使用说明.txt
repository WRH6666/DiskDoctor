DiskDoctor —— 怎么开始
================================================================

双击  DiskDoctor.cmd      <-- 就点这个

会出现一个菜单：

  [1] 盘点磁盘内容        <-- 第一次用请先点这个
      扫描完会自动打开浏览器界面。里面能看清每个目录是什么、
      能不能删，点任意路径可以直接跳到那个文件夹去看。

  [2] 执行清理
      在浏览器界面里勾选好、点「导出清单」之后，回到这个菜单
      点 [2]。它会先试运行给你看会动哪些东西，你确认后才执行。

  [3] 查看 / 还原暂存区
      清理掉的东西先进暂存区（不是真删），可以整体撤回来。

  [9] 换个扫描位置
      默认扫描你的用户目录。想扫整个 C 盘就选这个。

  [0] 退出


文件说明
----------------------------------------------------------------

  DiskDoctor.cmd    双击入口（点这个）
  DiskDoctor.ps1    菜单程序
  diskdoctor.exe    程序本体
  使用说明.txt      本文件

这几个文件要放在同一个文件夹里，不要拆开。


扫描结果在哪
----------------------------------------------------------------

会生成一个「DiskDoctor-输出」文件夹，就在这几个文件旁边，
里面是浏览器界面和报告。

如果程序所在目录不能写（比如放进了 Program Files），
会自动改写到  %LOCALAPPDATA%\DiskDoctor\out


建议以管理员身份运行
----------------------------------------------------------------

右键 DiskDoctor.cmd -> 「以管理员身份运行」

否则回收站、部分 AppData、卷影副本等位置读不到，
报告里会标注「因权限跳过 N 处」。


系统要求
----------------------------------------------------------------

只支持 Windows。
需要系统自带 PowerShell 5.1（Windows 10/11 都有，无需安装）。
不需要装 Rust 或其它任何东西。


它不会删你没确认的东西
----------------------------------------------------------------

  · [1] 盘点全程只读，不碰任何文件
  · [2] 先试运行，再等你输入 y 才动手
  · 清理是把文件移进暂存区，可以撤销
  · 暂存区里确认无误后才真正释放空间
  · Windows / Program Files / 回收站 / hiberfil.sys 等
    系统关键路径是硬编码挡住的，规则库改不了也绕不过
